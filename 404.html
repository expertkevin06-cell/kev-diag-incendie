Causes fréquentes
📦 Ancien cache APK

L’APK charge encore une version précédente. Utilisez « Réparer cache APK » puis rouvrez l’application.

🔗 URL de lancement erronée

Le raccourci pointe vers un fichier supprimé. La redirection renvoie vers la racine stable du projet.

🌐 Fichier manquant en ligne

Si index.html est absent du dépôt, la redirection échouera : vérifiez le déploiement GitHub Pages.
