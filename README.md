# 🔥 Étude incendie technique by Kevin — Base massive prédictive

Application scientifique d'investigation incendie avec **recherche prédictive par marques, modèles, motorisations, puissances** et **corrélations de pannes connues**.

## ✨ Fonctionnalités principales

### 🧠 Moteur prédictif multi-marques
- **Inférence automatique** : marque → modèle → motorisation → puissance à partir d'un mot-clé
- **Corrélations véhicule-panne** : probabilités basées sur les pannes connues documentées
- **Analyse causale prédictive** : origine, mécanisme, conséquences déterminés automatiquement
- **Base massive** : 25+ marques, 15+ modèles, 15+ motorisations, 16+ corrélations

### 🔍 Recherche unifiée
- Recherche par **véhicules** (ex: "308 1.2 PureTech 110ch", "Golf 7 TSI", "Kona électrique")
- Recherche par **pannes connues** (ex: "courroie humide", "crépine", "FAP herbe")
- Recherche par **DTC** (codes défaut)
- Recherche par **méthode scientifique** (NFPA 921)
- Recherche par **veille technique** (rappels, références)
